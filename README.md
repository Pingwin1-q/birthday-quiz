# 🎂 Birthday Quiz — Квиз & Лотерея

Шуточный сайт-квиз ко дню рождения с «подкрученным» колесом фортуны.  
Всегда выпадает приз: **Страховка на машину** 🚗

## Как это работает

1. Приветственный экран
2. 6 шуточных вопросов с забавными реакциями
3. Колесо фортуны (всегда останавливается на «Страховка на машину»)
4. Финальный экран с полисом и конфетти

## Быстрый старт (локально)

Просто открой `index.html` в браузере. Или запусти локальный сервер:

```bash
cd birthday-quiz
python3 -m http.server 8080
# Открой http://localhost:8080
```

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub (например `birthday-quiz`)
2. Загрузи все файлы из этой папки
3. В настройках репозитория: **Settings → Pages → Source: Deploy from branch**
4. Выбери ветку `main` и папку `/ (root)`
5. Сайт будет доступен по адресу: `https://ТВОЙ_ЛОГИН.github.io/birthday-quiz/`

## Кастомизация

### Заменить полис на настоящее фото

В `index.html` найди блок `<div class="certificate">` и замени его на:

```html
<div class="certificate-wrap">
  <img src="assets/insurance.jpg" alt="Страховой полис" style="width:100%;border-radius:4px;">
</div>
```

Положи фото в `assets/insurance.jpg`.

### Изменить вопросы

Отредактируй массив `QUESTIONS` в `js/app.js` — добавь свои вопросы, ответы и шуточные реакции.

### Изменить призы на колесе

Отредактируй массив `WHEEL_PRIZES` в `js/app.js`.  
Последний элемент — выигрышный приз. Не меняй `WINNING_INDEX`, если хочешь, чтобы всегда выпадала страховка.

### Персонализировать полис

Отредактируй `assets/insurance.svg` — имя, номер полиса, текст.

### Изменить финальное поздравление

В `js/app.js` найди функцию `showPrize()` и поменяй текст в `els.prizeMessage`.
